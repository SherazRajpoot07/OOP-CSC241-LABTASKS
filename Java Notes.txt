Important methods of LocalDate
Method	Purpose
LocalDate.now()	Gets today's date

getMonth()	Gets the month name

isBefore(date)	Checks whether a date is earlier
isAfter(date)	Checks whether a date is later

2. java.util.Locale
Locale is a class used to represent a particular language and regional setting.

For example:
- English (United States)
- English (United Kingdom)
- Urdu (Pakistan)
- French (France)

Important methods of Locale
Method	Purpose
Locale.getDefault()	Gets the system's default locale
getLanguage()	Gets language code
getCountry()	Gets country code
getDisplayLanguage()	Gets readable language name
getDisplayCountry()	Gets readable country name
